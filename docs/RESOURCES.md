# Free resources (and what to check before using)

| Type | Source | Licence note | Status |
|---|---|---|---|
| Music | Pixabay Music | Pixabay licence; **check the track page for "Content ID Registered"**, which can trigger claims on YouTube | Used (cut 4). Prefer tracks without the flag |
| SFX | Mixkit | Mixkit Sound Effects Free License | Used (57 files) |
| SFX | Openverse (CC0 filter) | Per-file; keep the CSV of title, creator, source | 23 CC0 files fetched |
| SFX | Sonniss GameAudioGDC bundles | Royalty-free, no attribution | Needs a human browser download (Cloudflare blocks scripts) |
| SFX | Soundly Free, A Sound Effect Cloud, Freesound | Account required | Human |
| HDRI / 3D | Poly Haven | CC0 | Used for Blender lighting |
| Icons | Lucide | ISC | Fetched |
| Fonts | Geist, Geist Mono | SIL OFL | Used |
| Images | Product's own site via headless Chrome | Needs the client's permission to show real UI | Used with the director's go-ahead; client sign-off tracked |
| Generative images | ComfyUI + open models | Check each model's licence for commercial use (SDXL base: OpenRAIL++) | Testing |

Rule: log every asset (source URL, licence, date, where used) the moment it enters a project.
